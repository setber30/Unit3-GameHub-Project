GameHub 5: Image & Text Sections

Unit 3 · Lesson 5 · Reference

A section can be a row of two halves: a picture and its words. flex: 1 makes the halves equal, and object-fit: cover lets a picture fill a box without being stretched.

The row

The section itself is the flex container. Its two children are the picture and the words; gap is the space between them.

.split { display: flex; align-items: center; gap: 40px; }

Equal halves

flex: 1 on both children tells each to take an equal share of the row, at any screen width.

.split-media, .split-text { flex: 1; }

The other way round

row-reverse draws the items right to left. The HTML order does not change, so a screen reader still reads them in the written order.

.split-reverse { flex-direction: row-reverse; }

Fill without squashing

A picture given a width and a height is stretched to fit. object-fit: cover fills the box and crops what hangs over, so the picture keeps its shape.

.split-media img { width: 100%; height: 320px; object-fit: cover; }

Zoom inside a window

overflow: hidden on the box keeps the grown picture inside it. The transition goes on the resting rule, as on day 4.

.split-media { overflow: hidden; border-radius: 12px; } .split-media img { transition: transform 0.4s; } .split-media:hover img { transform: scale(1.06); }

A button you can read

A white outline button disappears on a light section. Give the ones inside a split a dark border and dark text; the hero keeps its white pair.

.split .btn-secondary { border-color: var(--primary); color: var(--primary); }
